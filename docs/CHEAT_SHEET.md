# 🎹 NIME Controller - Performance Cheat Sheet

```
LEFT HAND                          RIGHT HAND
┌──────────────────────┐          ┌──────────────────────┐
│  [1][2][3][4][5]     │          │ I  M  R  P           │
│   ↓  ↓  ↓  ↓  ↓      │          │ ↑  ↑  ↑  ↓    ↑      │
│  Scale Degrees       │          │+8 #  ♭ -8    SHIFT  │
└──────────────────────┘          └──────────────────────┘
  + Hand → Waveform                   T = Thumb/Shift
    FAR=Smooth / CLOSE=Bright
```

## 🎯 SINGLE BUTTON ACTIONS (Thumb NOT held)
| Button | Action |
|--------|--------|
| **INDEX (I)** | ⬆️ Octave UP |
| **PINKY (P)** | ⬇️ Octave DOWN |
| **MIDDLE (M)** | ♯ Sharp (hold) |
| **RING (R)** | ♭ Flat (hold) |

## ⚡ SHIFT COMBOS (Hold THUMB + ...)
| Combo | Effect |
|-------|--------|
| **T + I** | 🎵 Major Pentatonic |
| **T + M** | 🎸 Blues Scale |
| **T + R** | 🎹 Chromatic |
| **T + P** | 🔒 Toggle Latch (ON/OFF) |

## 🎼 CHORD MODES (Hold both)
| Buttons | Mode |
|---------|------|
| **I + M** | Major Chord |
| **I + R** | Minor Chord |
| **Release both** | Return to Single Note |

## 🔑 KEY CHANGE
**Hold M + R** → Left buttons select root note → Release to confirm

---

## 💡 QUICK PERFORMANCE MOVES

**🎼 Build Latch Chord:**
1. `T + P` to enable latch
2. Tap left buttons (each stays ON)
3. `T + P` again to clear all

**🌊 Waveform Control:**
- Hand **FAR** = Smooth sine tone
- Hand **CLOSE** = Bright triangle tone
- Works on ALL playing notes

**⬆️⬇️ Jump Octaves:**
- Rapid **INDEX** taps = climb up
- Rapid **PINKY** taps = descend down
